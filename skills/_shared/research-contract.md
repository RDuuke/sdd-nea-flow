# Optional Development Research

Use in EXPLORE or a scoped unresolved design question when external evidence
would change a decision. It is not an additional required phase or gate.

- Identify the question, outcome, constraints and existing project evidence.
  Do not repeat settled product questions or use a fixed questionnaire.
- Use actual permitted tools and prefer primary sources. Attribute claims to
  URLs/supplied sources; distinguish facts, assumptions, contradictions, freshness
  limits and gaps. Never claim an unavailable lookup ran.
- Scale depth to uncertainty and consequences. Return concise findings,
  alternatives, remaining decisions and implementation implications.
- The coordinator owns user decisions. Workers report gaps rather than
  interviewing the user or inventing preferences.
- Missing optional research does not block independent authorized work. Pause
  only decisions dependent on unresolved choices or required missing evidence.
- Persist in the existing authorized OpenSpec artifact when applicable;
  otherwise return inline. No extra research proposal, store handshake, memory
  mirror or Engram dependency. Preserve history and verify actual writes.
